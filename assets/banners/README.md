# Banner Images

Drop one PNG per profile banner here. **The filename must exactly match the banner `id`** (from `getProfileBanners` in `core.js`) with a `.png` extension — that's how the app will look each one up.

- Recommended: wide banner, transparent or full-bleed background, ~1200×400 px (3:1). This is the image shown above the profile in the Quests tab.
- Format: `.png` (tell me if you'd rather use another format).
- One image per id; locked banners are rendered dimmed/greyed by the app.
