# Badge Images

Drop one PNG per achievement badge here. **The filename must exactly match the badge `id`** (from `getAchievementBadges` in `core.js`) with a `.png` extension — that's how the app will look each one up.

- Recommended: square, transparent background, ~512×512 px.
- Format: `.png` (if you'd rather use another format, tell me and I'll adjust the loader).
- Locked badges will render the same image dimmed/greyed by the app — you only need one image per id.
